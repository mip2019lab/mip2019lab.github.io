修改 hosts 文件（手动挡，技术向）

这是最经典的方法，原理是绕过正常的DNS解析，手动把 github.com 及其相关域名的IP地址“固定”下来，让你直连一个速度快的节点。

📥 操作步骤

1. 获取最新IP：打开 GitHub520 项目页面，复制它提供的、最新的 hosts 文件内容。

✏️ 修改 hosts 文件
  • Windows：文件在 C:\Windows\System32\drivers\etc\hosts。用记事本打开，把刚才复制的内容粘贴到最后，保存即可。如果提示没权限，可以先把文件拖到桌面，改完再拖回去覆盖原文件。
  • Mac / Linux：文件在 /etc/hosts，用 sudo 权限编辑（比如 sudo vim /etc/hosts）。
🔄 刷新 DNS 缓存

让修改立刻生效：

  • Windows：在命令提示符运行 ipconfig /flushdns
  • Mac：运行 sudo killall -HUP mDNSResponder
  • Linux：可尝试 sudo systemctl restart systemd-resolved 或 sudo service nscd restart
💡 小提示： 如果觉得手动操作麻烦，可以配合自动脚本或图形工具。但手动修改是最直接、最可控的方式。
注意将etc文件夹“属性”设置为可读写权限；vscode等编辑器运行“自动更新hosts软件（tkinter）”，如果链接延迟，可以手动下载hosts，然后覆盖系统hosts文件。
